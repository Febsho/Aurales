# Retired Netflix avatar catalog

This normalized metadata catalog is generated from the static icon catalog in
[`Angel2mp3/Bring-Back-Netflix-Icons`](https://github.com/Angel2mp3/Bring-Back-Netflix-Icons).
It contains identifiers, labels, categories, and remote image URLs only. Aurales
does not run the upstream userscript and does not access Netflix accounts,
cookies, GraphQL, or authentication endpoints.

The image artwork and marks remain the property of Netflix and their respective
rights holders. The catalog is included for profile-avatar selection only.
